百家樂數據分析站 - GitHub Pages 免費部署 ======================================== 檔案：index.html（整個網站只有一個 HTML 檔） 功能： - 手動記錄每局莊/閒/和、來源類型、靴號與局數 - 歷史比例、最近100局路單、連莊連閒分布 - 事前預測回測、估算損益 - CSV 匯出備份與 CSV 匯入 - 本機 localStorage 保存，不會自動上傳資料 重要： - 預測不保證下一局。 - API_UNVERIFIED 不等於真實牌局；VERIFIED_REAL 只用於可核驗來源。 - 此版不會自動連線抓取賭場資料。 - GitHub Pages 網站是公開可瀏覽的，但本機紀錄存在使用者自己的瀏覽器；換裝置不會自動同步。 - 請先匯出 CSV 備份。 iPhone 操作部署： 1. Safari 開 https://github.com/signup 註冊帳號並驗證信箱。 2. 登入後點 https://github.com/new 建立公開 repository。 3. Repository name 輸入「你的GitHub使用者名稱.github.io」（例如 username.github.io），勾選 Add a README file，按 Create repository。 4. 進入 repository，按 Add file → Create new file。 5. 檔名輸入 index.html，將本套件中的 index.html 全文貼上，按 Commit changes。 6. 進入 Settings → Pages。 7. 在 Build and deployment 的 Source 選 Deploy from a branch；Branch 選 main，資料夾選 /(root)，按 Save。 8. 等待幾分鐘，網址會是 https://你的使用者名稱.github.io 。GitHub 說明有時需要最多約 10 分鐘。 9. 將網址加入 iPhone 主畫面：Safari 分享 → 加入主畫面。 GitHub 官方說明： https://docs.github.com/en/pages/quickstart
